# ChartGrid

Finviz `Futures Charts` 风格的期货图表网格，图上叠加**两极移动平均线（Two-Pole Moving Average）**，
并支持**日/周/月/季**四档周期与 **NW 带 / MACD / RSI / TD9** 指标。
纯静态站点：无框架、无依赖、单文件渲染器，数据由 GitHub Actions 每日抓取。

线上地址：`https://ryanzhao2026.github.io/ChartGrid/`

---

## 1. 两极均线

「两极」指的是滤波器里有**两个储能极点**——把同一个一阶平滑级联两次，就得到二阶（two-pole）低通。
它不是把周期调大，而是改变滤波器的阶数：同样周期下，两极比单极更平、拐点更晚、假信号更少。

默认实现是**级联 EMA**（`a = 2/(N+1)`）：

```
p1[i] = p1[i-1] + a*( x[i] - p1[i-1] )      <- 第一极
p2[i] = p2[i-1] + a*( p1[i] - p2[i-1] )     <- 第二极，输出 p2
```

也可切换为 **SMA 的 SMA**：

```
p1 = SMA(x, N)
p2 = SMA(p1, N)                             <- 输出 p2
```

两者 DC 增益都是 1，**不缩放价格绝对水平**，只影响相位滞后与平滑强度。

### 实测特性（node 自检）

| 检验项 | 一极（单 EMA） | 两极（级联） |
|---|---|---|
| 常数输入 42 的稳态输出 | 42.000000 | 42.000000（DC 增益 = 1） |
| 阶跃达到 90% 所需根数 | 24 | 39（滞后明显更大） |
| 价格平均二阶差分（抖动） | 原始 3.650 | 均线 0.036 |

**平滑度约提升 100 倍，代价是滞后增加约 1.6 倍**——这就是两极均线的取舍点。

> 若你的原始口径不同（如 Ehlers 二阶超平滑、或两条不同周期均线相减），
> 只需替换 `app.js` 顶部的 `cascadeEMA` / `smaOfSma` 两个函数，其余代码无需改动。

## 2. 时间周期：日 / 周 / 月 / 季

数据层只存**日线**，周线及更长周期在浏览器端用 `resample()` 实时聚合，口径与看盘软件一致：

| 周期 | 分组键 | 聚合规则 |
|---|---|---|
| 日线 `D` | 原始日期 | 不聚合 |
| 周线 `W` | 所在周的**周一**日期 | o=首根开盘，h=区间最高，l=区间最低，c=末根收盘，v=求和 |
| 月线 `M` | `YYYY-MM` | 同上 |
| 季线 `Q` | `YYYY-Qn` | 同上 |

好处：换周期**零网络请求**，一次加载后秒切；CI 不需要为每个周期各抓一份数据。

> 注意：周线/月线的开盘价取该区间第一根日线的开盘价、收盘取最后一根，
> 与你所用软件若有细微差异，通常是「按自然周/自然月切分」还是「按交易日计数」的口径区别。

## 3. 指标

四个指标都在**聚合后的收盘价**上计算（即看周线时用周收盘价算），与主流行情软件一致。
可勾选组合：均线 / NW带 / MACD / RSI / TD9 各自独立开关，MACD 与 RSI 画在下方独立子图。

### NW 包络（Nadaraya-Watson，默认带宽 8、倍数 3）

取自 LuxAlgo 的 Nadaraya-Watson Envelope，用**高斯核加权平均**代替 SMA 做「局部平均价」：

```
w(x)    = exp( -x² / (2h²) )                 <- 高斯权重，h = 带宽
center  = Σ(close[j] · w(i-j)) / Σ w(i-j)    <- 只用最近 radius = 4h 根
band    = SMA(|close - center|, 100) * mult  <- 平均绝对误差 × 倍数
upper   = center + band
lower   = center - band
```

带宽越大曲线越平滑（跟随越慢），倍数越大通道越宽（越不容易被突破）。
主图叠加：上下轨为青色/红色描边，中心线为灰色虚线，带内浅色填充，价格突破轨道时标 ▲▼。
打分逻辑中的「位置」因子即取当前价在 NW 带内的相对位置。

### MACD（默认 12, 26, 9）

```
line   = EMA(close, 12) - EMA(close, 26)
signal = EMA(line, 9)
hist   = line - signal
```

独立子图：柱状图（正绿负红）+ 蓝色 DIF 线 + 黄色 DEA 线，以 0 轴为基准。
自检：常数序列下 line/signal/hist 全部为 0.00000000。

### RSI 相对强弱（默认 14，Wilder 平滑）

```
RS  = avgGain / avgLoss
RSI = 100 - 100/(1+RS)
```

独立子图：紫色曲线 + 70/50/30 三条参考线（30/70 虚线，50 实线）。
自检：单调上涨 -> 100，单调下跌 -> 0，前 14 位为 NaN，值域严格落在 [0,100]。

## 4. 界面

| 区域 | 说明 |
|---|---|
| 周期 | 日线 / 周线 / 月线 / 季线 |
| 均线周期 | 2-400，默认 50 |
| 均线口径 | 级联 EMA / SMA 的 SMA（两极） / SMA / EMA / WMA / HMA / DEMA / TEMA / ZLEMA / KAMA / JMA（Jurik 近似） |
| NW 带宽 / 倍数 | 带宽 1-50（默认 8）、倍数 0.5-10（默认 3） |
| 显示根数 | 20-500，默认 130（长周期建议调小） |
| 指标勾选 | 均线 / NW带 / MACD / RSI / TD9（默认前四项除 RSI 外全开） |
| 分组 Tab | All / Indices / Rates / Energy / Metals / Grains / Softs & Meats / Currencies / Crypto |
| 悬停 | 显示该根日期、O/H/L/C，以及当前开启的各指标值 |
| 页脚 | 品种数、当前周期、均线参数、已开指标、根数、数据生成时间 |

卡片高度随子图数量自适应：无子图 324x200，一个子图 324x250，两个子图 324x300。
指标在 41 个品种上全量重算约在百毫秒级，点击「应用」即时重绘。
分组 Tab 上会显示该组的整体技术评估（趋势/动量/强度/衰竭/位置五因子加权打分）。

## 5. 目录结构

```
ChartGrid/
├── index.html              # 页面骨架 + 控件
├── style.css               # 暗色主题
├── app.js                  # 周期聚合 + canvas 渲染器 + 打分
├── indicators.js           # 纯指标计算（无 DOM 依赖，可单独复用）
├── fetch_data.py           # yfinance 抓取 -> data/*.json
├── requirements.txt
├── data/
│   ├── manifest.json       # 品种清单 / 状态 / 末值 / 生成时间
│   └── ES.json             # 每品种一份日线 OHLC
└── .github/workflows/deploy.yml
```

数据文件保持**日线**口径，页面按需加载后本地聚合，因此新增周期或指标都不需要改数据层。

## 6. 本地运行

```bash
pip install -r requirements.txt
python fetch_data.py --days 500          # 生成 data/*.json
python -m http.server 8000               # 必须走 HTTP，file:// 下 fetch 会被拦
# 打开 http://localhost:8000
```

只抓几个品种调试：`python fetch_data.py --only ES,GC,CL`

> **注意**：Yahoo 对数据中心 / 云服务器 IP 限流很严，沙箱、CI 之外的云主机常返回 429。
> 本项目的设计前提就是**取数放在 GitHub Actions 里跑**。本地抓取失败属预期现象。

## 7. 自动化

`.github/workflows/deploy.yml`：

- 触发：`push` 到 main、每周一至周五 22:10 UTC（美股收盘后）、手动 `workflow_dispatch`
- 步骤：安装依赖 -> `fetch_data.py` -> 若无变化跳过提交，否则 `pull --rebase` 后推送 -> 部署 Pages
- 单个品种失败不中断整体：`manifest.json` 标记 `status: "failed"`，页面自动跳过
- 全部失败时脚本返回非零退出码，CI 会红，便于发现上游变更

首次部署需在 **Settings -> Pages -> Source** 选择 **GitHub Actions**。

## 8. 已知限制

- 使用**连续合约**（`ES=F` 这类），换月处有跳空，不适合做精确的绝对价回测
- 长周期（月/季）在 500 根日线下样本不长：月线约 24 根、季线约 8 根，指标预热不足会显示为空或滞后
- NW 带的 MAE 用 `maeLen=100`（Pine 原版为 499），因每品种仅约 414-500 根日线，拉长窗口会让前期全为空白
- NW 带只实现**端点（因果）模式**：历史值不会随后续数据变化；Pine 原版的「重绘模式」会改写历史曲线，故未采用
- MACD 的 EMA 从序列首根开始递推，未做前 26 根丢弃处理，与部分软件的「预热丢弃」口径略有差别
- `NKD=F`、`LB=F`、部分软商品在 Yahoo 上覆盖不稳，失败即跳过
- 图表为日线及更长周期；分时数据不在本项目范围内
